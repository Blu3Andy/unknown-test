QUINS Flex Line: Optical Setup and First Article Inspection for SMT Lines

QUINS Flex Line is the optical inspection system for SMT production lines. The system is mounted directly onto a conveyor belt and supports setup inspection, first article inspection and sample inspection before soldering.

Through fast image capture, optimized LED oblique-light illumination and automatic documentation, QUINS Flex Line helps detect placement errors early, avoid batch defects, and make inspection processes directly on the line more reliable.

QUINS Flex Line is specifically designed for SMT processes. The system is not a THT solution and not a classic stand-alone inspection system, but a line-side inspection solution for control before the soldering process.

In short: What is QUINS Flex Line?

QUINS Flex Line is an optical inspection system for SMT lines. It is mounted directly onto a conveyor belt in the production line and supports setup inspection, first article inspection and sample inspection before soldering. The system inspects SMT assemblies for presence, polarity, position, component value and visible optical defects. QUINS Flex Line is designed for SMT processes and is not positioned as a THT or stand-alone system.

Optical Inspection Directly on the SMT Line

QUINS Flex Line was developed for electronics manufacturers who want to inspect SMT assemblies early in the process. The ideal inspection point is directly on the line before soldering. This allows setup errors, placement errors or deviations to be detected before they affect further assemblies.
Typical applications include:
  • Setup inspection in SMT production
  • First article inspection before series release
  • Sample inspection directly on the line
  • Component inspection before soldering
  • Checking presence, polarity and position
  • Inspection of component values and visible deviations
  • Release inspection after line changeover
  • Inspection before reflow soldering
  • Avoiding batch defects
  • Automatic documentation of inspections
  • Traceability for release and inspection processes
Especially with frequent product changes, small and medium batch sizes, or high-mix manufacturing, QUINS Flex Line helps release the SMT line faster and more reliably.

Which Defects Does QUINS Flex Line Detect?

QUINS Flex Line supports the optical inspection of SMT assemblies for visible deviations before soldering. The system helps identify typical setup, placement and component orientation errors at an early stage.

Presence Inspection

QUINS Flex Line supports checking whether the intended components are present on the assembly. Missing components can be detected before the next process step.

Polarity Inspection

Polarized components must be correctly oriented. QUINS Flex Line helps make incorrectly oriented or reversed components visible.

Position Inspection

Shifted, rotated or misplaced components can lead to quality problems. QUINS Flex Line supports the optical inspection of component position directly on the line.

Component Value Inspection

Where component markings, printed labels or visual features are inspectable, QUINS Flex Line can support checking component values and component variants.

Typical Defect Patterns

  • Missing component
  • Wrong component
  • Extra component placed
  • Shifted component
  • Rotated component
  • Reversed polarity component
  • Defective component
  • Incorrect component value
  • Incorrect component position
  • Incorrect PCB or assembly variant
  • Visible optical deviations before soldering
The goal is to detect defects not after soldering or during final inspection, but as early as possible in the SMT process.

How Inspection with QUINS Flex Line Works

1. Set Up the SMT Line

After a product change, setup, or program change, the SMT line is prepared. Components, feeders, PCBs, placement data and inspection requirements must match.

2. Feed the Assembly via the Conveyor Belt

QUINS Flex Line is designed for mounting onto a conveyor belt. The assembly moves directly from the production line into the inspection area.

3. Capture the Image

The system captures the assembly via a CMOS camera. Synchronized dual image capture and optimized LED oblique-light illumination support consistent image quality across the inspection area.

4. Check Inspection Criteria

Depending on the inspection task, presence, polarity, position, component value and visible optical defects are checked. This supports setup inspection, first article inspection and sample inspection.

5. Evaluate and Document the Result

The inspection result is documented in a traceable way, creating a clear basis for release, rework, traceability or process optimization.

6. Release Production or Correct the Process

If the inspection passes, production can continue. In case of deviations, the cause can be checked and corrected directly on the line before further assemblies are affected.
