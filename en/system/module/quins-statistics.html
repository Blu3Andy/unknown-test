What is Quins Statistics?

Quins Statistics is the analysis module within the QUINS software environment. It takes existing test, error and repair data from connected QUINS systems and displays them in tables, diagrams and quality overviews.
Quins Statistics does not detect errors on the assembly itself. The module makes already recorded quality data comparable and helps identify recurring errors, unusual developments and potential process variations.
Comprehensive data analysis

What data does Quins Statistics evaluate?

Depending on system configuration and data collection, the following data can be evaluated:
Test results: Number of assemblies tested, passed and rejected tests, retests and releases
Error data: Error type, position, component, designator, package type, product, order, time, test station, line and shift
Repair data: Repaired errors, open repairs, pseudo errors, scrap and retest status
Traceability data: Serial number, batch, order, product variant, user, test station, date and time

Important Evaluations

Yield analysis: Shows quality yield over a selected period and helps determine if the percentage of successful tests remains stable, increases or decreases.
Error type overview: Errors are grouped by defined categories to show which deviations occur most frequently.
Error trend: Time series show whether specific errors occur more or less frequently and help identify trends early.
Component error analysis: Errors can be evaluated by component, part number or package type, if this data is available.
Position analysis: Frequently rejected positions within an assembly can be identified and optimized.
Scrap analysis: Scrap can be evaluated by product, order, error type or time period.
Repair analysis: Repair data shows which errors are reworked most frequently and how repair status develops.
Comparisons at all levels

Shift, Line and Location Comparison

Shift analysis: Test results and error rates of different shifts can be compared if shift information is available.
Line analysis: Production lines can be compared based on their test and error data to identify differences between equipment.
Location comparison: If data from multiple locations is consolidated centrally, quality metrics can be evaluated on a location basis.
