Proof, documentation and traceability

Document quality data transparently and traceably.

All information from your inspection and repair results is automatically assigned to the relevant order, project or test specimen. Quins View provides fast access to inspection logs, defect images, repair results and archive data – so quality processes can be retraced, complaints handled more effectively and open inspection or repair steps identified faster.
Important: Quins View does not detect defects itself. The module collects, visualises, manages and documents inspection and repair data from the QUINS system.
Stored data

What information does Quins View manage?

Depending on the configuration in use, Quins View makes the following data centrally available for production and quality assurance.

Inspection logs

Inspection result, date, time, inspection station, operator, order, project, serial number and batch – displayed per order.

Defect logs & image archive

Defect location, defect type, image material and processing status. Inspection, reference and defect images are archived long-term by order or serial number.

Repair results

In combination with Quins Repair, processed defects, repair steps and final inspection results can be traced.

Order & project overview

Projects are displayed with status, associated orders, test specimens and available documentation data.

Serial number & batch traceability

Inspection and repair results can be uniquely assigned and filtered to an individual test specimen or a production batch.

How Quins View works

Quins View is not a standalone inspection system – it is the documentation and traceability module within the QUINS software environment. It makes the results from connected inspection stations visible, traceable and accessible long term.

Traceability

Which traceability levels does Quins View support?

Traceability means the unambiguous assignment of inspection and repair information. Quins View supports the following levels:
Order
Which inspections belong to a manufacturing order?
Project
Which product or inspection configuration was used?
Serial number
Which individual test specimen was inspected?
Batch
Which production or material batch does the specimen belong to?
Operator
Who inspected, evaluated or repaired, and when?
Station & timestamp
At which system was the inspection or release carried out and when?
Software

Which QUINS module does what?

Quins View is the right module for central documentation and traceability. Separate, coordinated modules handle the actual inspection, repair management and statistical analysis.

Quins Easy

The basis for simple optical inspection and structured inspection processes.

Quins Easy Plus

For advanced inspection tasks, first article inspection and optional automation functions.

Quins AIP

The automated inspection process supports standardised inspection sequences and recurring inspection tasks.

Quins UVI

For automated UV inspection, particularly for protective coatings and conformal coating.

Quins View

For automatic documentation and traceable inspection results.

Quins Repair

For repair and rework processes with clear feedback on identified defects.

Quins Statistics

For evaluations, KPIs and quality analyses based on inspection data.

Quins Tools

For data control, setup support and preparatory inspection processes.
