QUINS AIP - automatic inspection software for PCBs and assemblies.

QUINS AIP extends QUINS Easy Plus with an automatic inspection process. After image capture, the software analyzes defined component features and checks presence, position and polarity. Detected deviations are clearly displayed for the inspection staff.

Quins AIP

What is Quins AIP?

Quins AIP is an optional extension for Quins Easy Plus. While Quins Easy Plus manages projects, reference images and assembly information, AIP handles the automatic analysis of defined optical features.
After image acquisition, the software inspects the assembly in the background. Deviations in presence, position or polarity are displayed at the corresponding component positions. The inspection staff evaluates the results and decides whether a finding is confirmed, rejected or additionally checked using visual image inspection.

Quins UVI

What is Quins UVI?

Quins UVI is an optional software upgrade for Quins Easy Plus for automatic inspection of fluorescent protective varnishes on PCBs and electronic assemblies.
With UVI, you can automatically and reliably inspect UV-active protective coatings. The software analyzes the fluorescence properties of the coating and detects deviations, missing areas or insufficient coverage – automatically and consistently.
Benefits

Why use Quins UVI?

  • Automatic Varnish Inspection: UV-active protective varnishes are automatically and reliably analyzed.
  • Consistent Results: Standardized inspection eliminates subjective factors from manual control.
  • Flexible Varnish Handling: Parameters can be adjusted on a project basis for different UV varnishes.
  • Manual Rechecking Possible: Suspicious areas can be additionally checked using visual image inspection.
  • Reliable Quality Assurance: Suitable for first sample and series inspections.
