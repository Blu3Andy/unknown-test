Willkommen bei QUINS Pro

Dieses System demonstriert, wie du HTML-Komponenten dynamisch laden kannst, statt sie in 52 verschiedenen Dateien zu duplizieren.

Wie funktioniert es?

  1. Komponenten erstellen: Lege HTML-Dateien im `components/`-Ordner an (z.B. `header.html`, `footer.html`)
  2. Placeholder einfügen: Füge `<div data-include="components/header.html"></div>` ein
  3. Script einbinden: Füge `<script src="js/load-components.js" defer></script>` ein
  4. Fertig! Der Header wird automatisch beim Laden der Seite eingefügt

Vorteile dieses Ansatzes:

  • ✓ Zentrale Verwaltung: Ändere den Header nur an einer Stelle
  • ✓ Keine Code-Duplizierung: Sparen Sie 51 Kopien
  • ✓ Wartbar: Updates betreffen alle Seiten automatisch
  • ✓ Vanilla JavaScript: Kein Framework, keine Build-Tools notwendig
  • ✓ Kleine Dateigröße: Nur ~2KB JavaScript

Migration zu diesem System:

Für jede deiner 52 HTML-Dateien:

  1. Entferne den kompletten Header-HTML-Code (die ~450 Zeilen)
  2. Ersetze ihn mit: `<div data-include="components/header.html"></div>`
  3. Füge am Ende des `<body>` ein: `<script src="js/load-components.js" defer></script>`

Fertig! Jetzt kannst du den Header zentral verwalten.

Beispiel (Vorher vs. Nachher):


<div data-w-id="..." class="uui-navbar02_component w-nav">
  ... 450+ Zeilen HTML ...
</div>


<div data-include="components/header.html"></div>

Weitere Komponenten erstellen:

Du kannst das gleiche System für andere Teile nutzen:

  • `components/footer.html` - für einen Footer
  • `components/sidebar.html` - für eine Seitenleiste
  • `components/breadcrumb.html` - für Breadcrumbs
  • Alles was du magst!
